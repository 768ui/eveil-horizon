# Éveil Horizon

Site vitrine responsive pour Éveil Horizon — accompagnement, développement personnel, ateliers collectifs, boutique numérique et espace client.

## Pages incluses
- `index.html` : page d’accueil
- `services.html` : accompagnements individuels
- `collective.html` : accompagnements collectifs pour entreprises et structures
- `tarifs.html` : tarifs, réservations et liens Calendly
- `boutique.html` : boutique numérique avec produits téléchargeables
- `contact.html` : formulaire de contact avec réseaux sociaux
- `espace-client.html` : espace client de démonstration
- `admin.html` : interface admin de démonstration
- `style.css` : styles globaux et responsive
- `app.js` : interactions menu, formulaires et mini-demo
- `assets/logo.svg` : logo vectoriel Éveil Horizon

## Pré-requis
Ouvrez simplement le site dans votre navigateur :

- `index.html` pour voir la vitrine

Ou lancez un petit serveur local :

```bash
python3 -m http.server 8000
```

Puis ouvrez : http://localhost:8000

## Personnalisation rapide
- Remplacer le logo dans `assets/logo.svg`
- Modifier les liens Calendly dans `tarifs.html`
- Ajuster les réseaux sociaux dans `contact.html` et `index.html`
- Mettre à jour les tarifs directement dans `tarifs.html`

## Point de sécurité
- Aucune donnée bancaire, personnelle ou confidentielle n’a été intégrée dans ce dépôt public.
- Les zones client/admin sont des démonstrations front-end et doivent être reliées à une vraie authentification / base de données en production.

## Hébergement gratuit
Cette version est compatible avec une publication via GitHub Pages pour la vitrine static HTML/CSS/JS.
